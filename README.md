# Training Center Management System

A desktop application developed to manage a training center's daily operations, including students, courses, enrollments, payments, and user accounts.

Key Features:

Manage student and course profiles.
Handle course enrollments and enrollment status.
Track student payments and payment history.
Manage users and system access.
Apply business rules and validation for enrollments and payments.

Technologies: .NET Framework (C#), WinForms, SQL Server, T-SQL (Stored Procedures), ADO.NET.

Architecture: 3-Tier Architecture (Presentation, Business Logic, and Data Access Layers).
